# Power

A personal AEM Edge Delivery / Document Authoring corpus of Robert Greene’s *48 Laws of Power*.

- **Object:** Alcibiades (Capitoline type, Dualform A marble / B living)
- **Org:** [somarc/power](https://github.com/somarc/power)
- **Preview:** https://main--power--somarc.aem.page/
- **DA:** https://da.live/#/somarc/power/

Original commentary only. Canonical law titles. Historical cases from Plutarch, Thucydides, Xenophon, Plato. Present cases from the 2025–26 public record.

```bash
da --org somarc --repo power status --format json
python3 tools/render_corpus.py
```
